# Go HTTP Server: Basic Counter & Routing

Простой веб-сервер на Go (Golang), демонстрирующий работу с HTTP-запросами, маршрутизацией и глобальным состоянием.

## 🚀 Функционал

Сервер запускается на порту `:8080` и предоставляет три эндпоинта:

| Метод | Путь | Описание |
| :--- | :--- | :--- |
| `GET` | `/hello` | Возвращает простое приветствие "hello world". |
| `GET` | `/get` | Возвращает текущее значение счетчика `Counter`. |
| `POST` | `/post` | Увеличивает счетчик `Counter` на 1. |

## 🛠 Технологии

*   **Язык:** Go (Golang)
*   **Пакеты:** `net/http` (стандартная библиотека), `fmt`, `strconv`
*   **Архитектура:** Использование `http.NewServeMux` для маршрутизации.

## 📚 Что изучено в ходе разработки

1.  **Создание HTTP-сервера:** Запуск сервера через `http.ListenAndServe`.
2.  **Маршрутизация (Routing):** Регистрация обработчиков через `ServeMux.HandleFunc`.
3.  **Обработка методов:** Различение `GET` и `POST` запросов внутри хендлеров (`r.Method`).
4.  **Работа с состоянием:** Использование глобальной переменной для хранения данных между запросами.
5.  **Формирование ответа:** Отправка текстовых данных клиенту через `http.ResponseWriter`.
6.  **Преобразование типов:** Конвертация `int` в `string` с помощью `strconv.Itoa`.

## ▶️ Как запустить

1.  Убедитесь, что установлен Go.
2.  Клонируйте репозиторий или сохраните код в `main.go`.
3.  Запустите сервер:
    ```bash
    go run main.go
    ```
4.  Проверьте работу через браузер или `curl`:

    ```bash
    # Приветствие
    curl http://localhost:8080/hello

    # Получить счетчик
    curl http://localhost:8080/get

    # Увеличить счетчик
    curl -X POST http://localhost:8080/post
    ```

## ⚠️ Примечания

*   В данной версии используется глобальная переменная `Counter`. Для продакшена рекомендуется использовать `sync.Mutex` или `atomic` для безопасности потоков (thread-safety).
*   Обработка ошибок методов выполнена вручную внутри хендлеров.
